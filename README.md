# Пульс — лендинг сервісного центру

Навчальний проєкт. Компанія, контакти й відгуки вигадані.

## Демо

https://kuzmenkoi633-alt.github.io/puls/

## Що є на сторінці

- **Шапка** — логотип, меню, телефон і кнопка «Заявка»; на телефоні меню ховається в бургер
- **Головний екран** — заголовок, короткий опис і дві кнопки
- **Послуги та ціни** — 6 карток з описом і ціною
- **Як ми працюємо** — 4 кроки від заявки до гарантії
- **Відгуки клієнтів** — 3 відгуки з оцінкою
- **Часті питання** — 4 питання, що розгортаються по кліку
- **Форма заявки** — ім'я, телефон і опис проблеми
- **Футер** — контакти й графік роботи

## Технології

- HTML, CSS (Grid, Flexbox, @media, :has()), JavaScript

## Що реалізовано на JS

- **FAQ-акордеон** — клік по питанню відкриває або закриває відповідь
- **Валідація форми** — перевірка імені, телефону й опису з підказками під полями
- **Бургер-меню** — відкриває меню на телефоні й закриває його після кліку на пункт

## Доступність

- `aria-expanded` на кнопках FAQ і бургера — скрінрідер знає, відкрито чи закрито
- `aria-label="Меню"` на бургері — кнопка без тексту має назву
- `role="img"` і `aria-label` на зірках — читається «Оцінка 5 з 5», а не п'ять символів
- `role="status"` для повідомлення форми — скрінрідер озвучує результат відправки
- `<label for>` для кожного поля форми й `autocomplete` для імені та телефону
- `prefers-reduced-motion` — плавна прокрутка вмикається, лише якщо користувач не вимкнув анімації
- Помітна рамка фокусу на полях форми
- Семантичні теги: `header`, `nav`, `main`, `section`, `footer`, `address`, `blockquote`
